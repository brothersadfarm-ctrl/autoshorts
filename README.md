# 🚀 AutoShorts v2.0 - Automated Short Video Stock & 24/7 Multi-Platform Publisher

AutoShorts হলো একটি স্বয়ংক্রিয় শর্ট ভিডিও পাবলিশিং প্ল্যাটফর্ম। আপনি আপনার শত শত শর্ট ভিডিও একসাথে ওয়েবসাইটের স্টক কিউতে আপলোড করে রেখে দিতে পারবেন। এরপর আপনার কম্পিউটার বা ল্যাপটপ বন্ধ থাকলেও, ক্লাউড সার্ভার নিজে থেকেই আপনার সেট করা নির্দিষ্ট সময়ে (যেমন: সকাল ৯টা, দুপুর ২টা, বিকাল ৫টা, সন্ধ্যা ৭টা, রাত ৯টা ইত্যাদিতে) ভিডিও তুলে নেবে, FFmpeg দিয়ে চ্যানেলের ওয়াটারমার্ক ও সাউন্ড মডিফাই করবে, Gemini AI দিয়ে ভাইরাল এসইও (Title, Description, Tags, Hashtags) তৈরি করবে এবং সরাসরি **YouTube Shorts** ও **Facebook Reels**-এ স্বয়ংক্রিয়ভাবে আপলোড করে দেবে।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

1. **📦 ভিডিও স্টক ও কিউ (Bulk Video Stock Queue)**:
   - একসাথে ৫০+ শর্ট ভিডিও ড্র্যাগ-অ্যান্ড-ড্রপ করে আপলোড করে জমিয়ে রাখার সুবিধা।
   - অটোমেটিক ভিডিও ডিউরেশন, ফাইল সাইজ ও রেজোলিউশন ডিটেকশন।
   - ব্রাউজারেই সরাসরি ভিডিও প্লেয়ার প্রিভিউ।
   - যেকোনো সময় "Publish Next Now" বাটনে ক্লিক করে ইনস্ট্যান্ট টেস্ট পাবলিশ করার অপশন।

2. **⏰ স্মার্ট টাইম ম্যানেজমেন্ট ও শিডিউলার (Multi-Slot Scheduler)**:
   - প্রতিদিনের যত খুশি টাইম স্লট যুক্ত করার সুবিধা (যেমন: সকাল ৯:০০, দুপুর ১৪:০০, বিকাল ১৭:০০, সন্ধ্যা ১৯:০০, রাত ২১:০০ বা যেকোনো সময়)।
   - ২৪ ঘণ্টার ভিজ্যুয়াল টাইমলাইন বার।
   - লাইভ কাউন্টডাউন টাইমার ("পরবর্তী পোস্ট হতে আর বাকি: ১ ঘণ্টা ২০ মিনিট")।
   - টাইমজোন সাপোর্ট (ডিফল্ট: `Asia/Dhaka` GMT+6)।
   - প্রতিটি স্লট আলাদাভাবে অন/অফ করার টগল সুইচ।

3. **🎨 ওয়াটারমার্ক ও সাউন্ড মডিফিকেশন ইঞ্জিন (FFmpeg Powered)**:
   - **ওয়াটারমার্ক লোগো**: আপনার চ্যানেলের PNG লোগো আপলোড, সাইজ (স্কেল), অপাসিটি এবং পজিশন (Top-Right, Top-Left, Bottom-Right, Bottom-Left, Center) নিয়ন্ত্রণ।
   - **অডিও নরম্যালাইজেশন (EBU R128)**: সোশ্যাল মিডিয়া স্ট্যান্ডার্ড অনুযায়ী অডিও স্বয়ংক্রিয়ভাবে স্পষ্ট, ক্রিস্প এবং লাউড করা।
   - **স্মার্ট অডিও টেম্পো মডিফাই**: মানুষের কানে স্বাভাবিক রেখে অডিওর অ্যাকোস্টিক ফিঙ্গারপ্রিন্ট সূক্ষ্মভাবে পরিবর্তন করে কপিরাইট বা ডুপ্লিকেট অডিও ফ্ল্যাগ এড়ানো।
   - **টেস্ট প্রিভিউ বাটন**: লাইভ পাবলিশ করার আগেই এক ক্লিকে ওয়াটারমার্ক ও অডিও মডিফাই টেস্ট করে প্রিভিউ দেখার সুবিধা।

4. **🤖 Google Gemini AI অটোমেটিক এসইও (Viral SEO Engine)**:
   - প্রতিটি ভিডিওর জন্য স্বয়ংক্রিয়ভাবে হাই-সিটিআর ভাইরাল টাইটেল (< ৮৫ অক্ষর + #Shorts)।
   - আকর্ষণীয় হুক ডেসক্রিপশন এবং ভাইরাল হ্যাশট্যাগ (#Shorts, #Reels, #Viral, #Trending)।
   - চ্যানেলের নিশ অনুযায়ী কাস্টমাইজড এসইও (যেমন: Facts, Motivation, Tech, Gaming, Comedy ইত্যাদি)।
   - বিল্ট-ইন ইন্টেলিজেন্ট ফলব্যাক ইঞ্জিন (Gemini API কী ছাড়াও স্বয়ংক্রিয়ভাবে এসইও তৈরি হবে)।

5. **🚀 মাল্টি-প্ল্যাটফর্ম পাবলিশিং ও সিমুলেশন মোড**:
   - **YouTube Shorts**: YouTube Data API v3 ইন্টিগ্রেশন।
   - **Facebook Reels**: Meta Graph API Reels ইন্টিগ্রেশন।
   - **Simulation Mode (সিমুলেশন মোড)**: এক ক্লিকে টগল করে কোনো লাইভ এপিআই কী ছাড়াই সম্পূর্ণ ভিডিও প্রসেসিং, এসইও ও শিডিউলার টেস্ট করার সুবিধা।

## ☁️ ২৪/৭ ক্লাউড সেটআপ (কম্পিউটার বন্ধ থাকলেও যেভাবে চলবে)

আপনার পার্সোনাল কম্পিউটার বা ল্যাপটপ বন্ধ থাকলেও যাতে অটোমেশন সফটওয়্যারটি ২৪ ঘণ্টা ভিডিও আপলোড চালিয়ে যেতে পারে, তার জন্য নিচের যেকোনো একটি পদ্ধতিতে এটি ক্লাউডে হোস্ট করে রাখুন:

### পদ্ধতি ১: Render.com (ফ্রি / ক্লাউড ওয়েব সার্ভিস) - সবচেয়ে সহজ
1. এই ফোল্ডারটি আপনার একটি GitHub রিপোজিটরিতে আপলোড/পুশ করুন।
2. [Render.com](https://render.com)-এ একটি ফ্রি অ্যাকাউন্ট খুলুন।
3. **New +** বাটনে ক্লিক করে **Web Service** সিলেক্ট করুন।
4. আপনার GitHub রিপোজিটরিটি কানেক্ট করুন।
5. সেটিংস দিন:
   - **Environment**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
6. **Deploy** বাটনে ক্লিক করুন।
7. ডিপ্লয় শেষে আপনি একটি ফ্রি লিঙ্ক পাবেন (যেমন `https://my-autoshorts.onrender.com`)। এখন আপনি আপনার মোবাইল বা যেকোনো ব্রাউজার দিয়ে ভিডিও আপলোড করে রাখবেন, আর আপনার কম্পিউটার বন্ধ থাকলেও রেন্ডার সার্ভার নির্দিষ্ট সময়ে ভিডিও পাবলিশ করতে থাকবে!

### পদ্ধতি ২: Docker ও Docker Compose (১-কমান্ডে যেকোনো সার্ভারে)
প্রজেক্টে সম্পূর্ণ রেডি `Dockerfile` এবং `docker-compose.yml` দেওয়া আছে। যেকোনো VPS বা সার্ভারে শুধু রান করুন:

```bash
docker compose up -d
```
এটি স্বয়ংক্রিয়ভাবে FFmpeg এবং Node.js কনটেইনার চালু করে ব্যাকগ্রাউন্ডে চালিয়ে রাখবে।

---

### পদ্ধতি ৩: কমদামী Ubuntu VPS (DigitalOcean / Hetzner / Contabo)
একটি $4-$5 ডলারের উবুন্টু সার্ভারে:
```bash
sudo apt update && sudo apt install -y ffmpeg nodejs npm
git clone <your-repo-link>
cd "automation short"
npm install
npm install -g pm2
pm2 start server/index.js --name "autoshorts"
pm2 startup
pm2 save
```
PM2 সার্ভার রিবুট হলেও স্বয়ংক্রিয়ভাবে সফটওয়্যারটি ব্যাকগ্রাউন্ডে চালু রাখবে।

## 🔑 YouTube ও Facebook API সেটআপ নির্দেশিকা

### YouTube Data API v3:
1. [Google Cloud Console](https://console.cloud.google.com/)-এ যান এবং একটি প্রজেক্ট তৈরি করুন।
2. **APIs & Services > Library** থেকে **YouTube Data API v3** এনাবল করুন।
3. **OAuth consent screen** কনফিগার করুন এবং **Credentials** থেকে **OAuth 2.0 Client ID** তৈরি করুন।
4. [Google OAuth 2.0 Playground](https://developers.google.com/oauthplayground)-এ গিয়ে আপনার Client ID এবং Client Secret দিয়ে `https://www.googleapis.com/auth/youtube.upload` সিলেক্ট করে একটি **Refresh Token** জেনারেট করুন।
5. AutoShorts ড্যাশবোর্ডের **YouTube ও Facebook সংযোগ** ট্যাবে Client ID, Client Secret এবং Refresh Token সেভ করে দিন।

### Facebook Reels API:
1. [Meta for Developers](https://developers.facebook.com/)-এ যান এবং একটি অ্যাপ তৈরি করুন।
2. **Graph API Explorer** থেকে আপনার পেজের জন্য `pages_show_list`, `pages_read_engagement`, `pages_manage_posts` পারমিশনসহ একটি **Page Access Token** জেনারেট করুন।
3. AutoShorts ড্যাশবোর্ডে আপনার **Page ID** এবং **Page Access Token** পেস্ট করে সেভ করুন।
